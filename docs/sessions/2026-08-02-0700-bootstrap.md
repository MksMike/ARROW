## Achados

**Download de ticks em andamento dentro do repositório.** Durante a sessão, uma ferramenta
externa estava baixando ticks Dukascopy XAUUSD para dentro de `C:\dev\ARROW`. Criou
`data/dukascopy/xauusd-tick-2022-08-01-2023-08-01.csv` (coberto pela regra `data/`), mas também
`.dukascopy-cache/` e `download/` **na raiz** — nenhum dos dois previsto na lista de `.gitignore`
que o `CLAUDE.md` especificava, num repositório público. Daí a regra acrescentada ao ADR 0004.

**A regra `tools/setup/local_paths.*` engolia o próprio modelo.** `local_paths.example.ps1` não
entrava no stage, o que deixaria uma máquina nova sem ponto de partida. Corrigido com negação
explícita.

**A janela de tick do broker não fecha o Gate 2.** O snapshot de 2026-07-30 em
`C:\dev\_mks-tick-snapshot-2026-07-30` cobre 2026-01 a 2026-07 — ~145 dias de negociação contra
os 250 que o Gate 2 exige, e a janela da Exness é móvel. `TickImport.mq5` foi reclassificado de
condicional para caminho crítico no `CLAUDE.md` §16.

### Correções factuais aplicadas ao `CLAUDE.md`

Fora o rename. Cada uma é correção de erro, não mudança de decisão:

1. **§16.3 — origem do clone.** Era `CustomSymbolCreate("XAUUSD.ARROW", ..., "XAUUSD")`. O símbolo
   do broker é **XAUUSDm**; `XAUUSD` não existe nesta corretora. Clonar de origem errada herda
   tick value, digits e contract size errados **em silêncio** — exatamente a armadilha que a §9
   existe para evitar.
2. **§16.3 — TickImport deixou de ser condicional**, pelo motivo em "Achados".
3. **§7 Gate 1 — `k` marcado como indefinido.** A fórmula `T_min = (c/kσ)²` não é executável. O
   valor **não foi inventado**; a lacuna foi sinalizada no texto e registrada como pendência.
4. **§11 — tabela marcada como premissa não verificada**, com a regra de que a medição vence.

## Perguntas para o chat

Quatro, em ordem de quanto bloqueiam:

1. **Qual o `k` de `T_min = (c/kσ)²`, e de onde ele sai?** Sem isso o Gate 1 inteiro não roda.
   É a pendência mais concreta do projeto.
2. **O que `confidence` significa?** O `SensorOut` declara `confidence` em `[0,1]` e nenhum
   documento diz o que o número mede, como é calculado, nem o que a camada de execução deve fazer
   com ele. O primeiro sensor vai ter que inventar uma semântica se isso não for decidido antes —
   e aí ela vira precedente por acidente.
3. **Qual a tese mecânica?** O `docs/CONTEXT.md` já aponta isso como o item mais importante em
   aberto. Há uma máquina de validação rigorosa e nenhuma hipótese declarada sobre o que gera
   desequilíbrio explorável no XAUUSD M1. Construir sensor antes disso é busca cega, e busca cega
   com muitos testes é o que a correção para testes múltiplos existe para punir.
4. **De onde veio a spec da §11?** O terminal está logado em conta demo. A tabela precisa ser
   confirmada contra o símbolo real — o `DataAudit` mede e reporta divergência.
